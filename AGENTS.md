# biz-terrace-ai-materials — Repository Agent Contract

Public repository for Biz-Terrace.ai published event materials and reproducibility cheatsheets. This contract is self-contained and must not depend on private workspace files.

- Commit only material approved for public distribution. Never add participant-only handouts, internal discussion, company-confidential information, credentials, private source paths, or unpublished drafts.
- Preserve per-event structure under `events/YYYY-MM-DD-<slug>/` and the documented author/license attribution.
- Slides/cheatsheets should describe observable steps and verification points without pretending a user's AI output is authoritative. Do not invent event facts or permissions.
- Read `CONTRIBUTING.md` when changing contribution/synchronization flow. This public repo is synchronized from a private source, so do not assume a public PR is automatically the canonical source update.
- Validate links/Markdown or event-specific examples proportionally to the changed material. A text correction does not require unrelated event content to be loaded.
- Respect CC BY-NC/MIT boundaries and third-party assets/trademarks; publication of new private-source material requires the existing approval path.

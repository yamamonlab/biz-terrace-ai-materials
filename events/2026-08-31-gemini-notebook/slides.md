# Gemini Notebookで学ぶ、調査から資料までをつなぐAI入門 — スライド構成

日付: 2026-08-31 / 登壇: 山門 樹（Biz-Terrace.ai 運営） / 所要: 60 分 / 8枚

各枚の要点だけを載せます。スライド本体は公開していません。

## 話の骨格

- 冒頭の問い: AIに質問するだけで、仕事は最後まで進むのか
- 転換点: 公開CSVを渡すと、AIがコードを書き、集計・可視化・資料化まで進められる
- 持ち帰る型: ゴール共有 → 利用条件 → デモ設定 → コード実行 → 人の検算 → PDF → 別環境への横展開
- 閉じの問い: 自分の仕事で、AIに任せるデータ処理と、人が確認する数字・前提はどこか

## 1. 今日、1本でつなぐ仕事（5分）

- 伝えたいこと: 公開CSVから、AIによるコード生成・実行、集計、グラフ、PDFまでをライブでつなぐ。見るだけの参加でよい
- 図: CSV → Python → 集計表 → グラフ → PDF

## 2. 利用条件と安全境界（5分）

- 伝えたいこと: コード実行の提供範囲はアカウント・プラン・Workspace設定で異なる。デモは公開CSVだけを使い、数字・欠損・単位・最終成果物は人が確認する
- 根拠: Google公式の機能説明
- 図: 利用可否 / 入力してよいもの / 人の確認点 の3区分

## 3. ツールではなく、仕事の型を見る（6分）

- 伝えたいこと: 持ち帰るのは製品操作ではなく「調査 → 集計 → 可視化 → 資料化」をAIへ委任し、人が検算する型。Microsoft 365 Copilot の Analyst などにも同じ見方を移せる
- 根拠: Google・Microsoft の公開機能説明
- 図: 中央に共通ワークフロー、左右にツール例

## 4. デモの問いと期待結果（4分）

- 伝えたいこと: 公開CSV、確認したい問い、期待する集計軸、正解を確かめるチェック値、最終成果物を「実行前に」共有する
- 図: 入力データの列、問い、期待する表・グラフ・PDF

## 5. AIがPythonを書いて実行する（18分・ライブデモ）

- 伝えたいこと: CSVを読み込み、AIが分析手順を考え、Pythonを生成・実行し、集計表とグラフを返す一連を実画面で示す
- 図: 指示 → 生成コード → 実行ログ → 集計表 → グラフ
- 運営メモ: 実行待ちやエラー復旧が90秒を超えたら、原因究明を続けずバックアップ動画へ切り替える

## 6. 出力を鵜呑みにせず、検算してPDFへ（9分）

- 伝えたいこと: 数字、欠損、単位、集計条件、グラフ表現を人が確認し、必要なら指示を修正する。確認後の表とグラフをPDFへまとめる
- 図: Before（初回出力）→ Check（人の確認）→ After（完成PDF）

## 7. 別環境でも、同じ仕事の型を使う（6分）

- 伝えたいこと: Googleを使えない環境でも、コードを使った分析・可視化をAIへ委任する考え方は移せる。製品比較ではなく、入力・実行・検算・成果物の役割で見る
- 図: 共通の4工程と環境別の実装例

## 8. 24時間アクション（7分）

- 伝えたいこと: 明日試す表形式データを1つ選び、AIに任せる処理と、人が確認する数字・前提を1つずつ決める
- 図: 「データ / AIへ任せる / 人が確認する」の3欄カード

## 話さなかったこと

- 全参加者が同じコード実行機能を使えるという保証
- プログラミング講座、Python文法の網羅、製品間の優劣ランキング
- AIが出した数字やグラフを、検算なしで正しいと扱うこと
- 未公開の企業データ、個人情報、顧客情報を使ったデモ
